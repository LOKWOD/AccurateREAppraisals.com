Information that helps us quote the assignment

  • property address and property type
  • why the appraisal is needed
  • client and intended users, if already known
  • effective date if the value is historical
  • deadline or court/filing date if applicable
  • property access contact
  • anything unusual about the property: waterfront, acreage, accessory buildings, major renovation or atypical use

You do not need to know appraisal terminology

If you are unsure whether you need a current appraisal, retrospective appraisal or another assignment type, simply explain the decision the value needs to support. We can identify what information is still needed to define the appraisal problem.
